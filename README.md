mend is one CLI patch tool for every AI edit format: unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and text-editor tool calls as JSON. It finds the lines each edit names even when whitespace or indentation drifted, and writes every change or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
